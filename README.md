# Python Calculator
A command-line calculator written in Python that supports basic
arithmetic, trigonometric functions, and robust input handling.
The program is designed to be user-friendly and resilient to
invalid input.

## Features
- Addition, subtraction, multiplication, and division
- Exponents and square root
- Trigonometric and inverse trigonometric functions (degrees-based)
- Stores the previous result and allows reuse using the "ans" keyword
- Maintains a history of recent calculations
- Handles invalid input and mathematical edge cases gracefully

## How to Run
1. Ensure Python 3 is installed
2. Clone the repository
3. Run the program
